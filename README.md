# 第五人格随机抽取工具 · PIL Identity V Lottery Tool

为第五人格对局随机生成 4 名求生者、1 名监管者，以及各自的人格配置和监管者辅助特质，并可把抽取过程实时同步给选手。

**[在线使用](https://pkuidv.com/lottery/)**

## 功能

- **随机阵容**：一次抽取 4 名不重复的求生者和 1 名监管者。
- **人格配置**：按 130 点人格点数生成配置，可分别设置双方的最终天赋数量；求生者可选择必点「绝处逢生」。
- **随机权重**：最终天赋设为随机时，可自定义抽到 0、1、2 个的权重，默认各 1/3。
- **辅助特质**：可以随机抽取，也可以关闭抽取，由监管者自选。
- **卡池设置**：分别管理求生者、监管者和辅助特质的抽取范围。
- **适配设置**：按角色排除用不上的人格和辅助特质，可逐条开关、逐个角色调整，也可一键重置。
- **房间同步**：选手输入 6 位房间号并选择身份后，抽取和重抽会实时同步，并按主控进度播放洗牌、翻牌、人格点亮与特质滚动；未揭晓的结果不会提前发送。
- **身份权限**：可为监管者、求生者、观众分别设置是否开放、密码和人数上限；每场结束后可重置房间，清空所有人和上一场结果。
- **可见范围**：分别设置双方能看到的敌方角色、人格、绝处逢生和辅助特质。
- **单项重抽**：保留其他结果，单独更换某个角色、人格或辅助特质。
- **结果分享**：复制完整结果或简略结果，也可以复制人格树图片。
- **揭晓动画与音效**：支持跳过动画，也可关闭音效。

## 使用方式

1. 在「卡池设置」和「适配设置」中确定抽取范围。
2. 设置双方的最终天赋数量、是否必点「绝处逢生」、是否抽取辅助特质。
3. 需要同步给选手时，打开「房间设置」，创建房间，设置可见范围、密码和人数上限，并把房间号发给选手。
4. 点击「抽取结果」生成本局配置。
5. 点击人格树查看详情，按需单项重抽，或复制结果。

隐藏了部分内容时，请为相关身份设置密码，否则知道房间号的人都能选择这些身份；观众能看到全部内容，不要把观众密码发给选手。换人或换边时，请同时更换密码。

卡池、适配、抽取选项和音效设置保存在当前浏览器中。

## 本地开发

需要 Node.js 24。

```bash
node server/dev.mjs
```

启动后打开 <http://127.0.0.1:4181/lottery/>。

运行测试：

```bash
node --test tests/*.test.mjs
```

有 Playwright 和 Chromium 的开发环境还可运行同步动画回归：

```bash
node tests/live-animation.browser.mjs
```

也可通过 `PLAYWRIGHT_MODULE` 指定现有 Playwright 模块的绝对路径。此测试会启动独立临时服务和数据库，覆盖三个视角、逐步揭晓、重抽、重连、跳过、减少动态效果和退出清理。

## 访问统计

主页面记录访问和经过白名单过滤的聚合操作，包括赞助入口点击。房间同步页只记录固定的 `/lottery/live/` 页面访问，不记录房间号、身份、口令、访问令牌或抽取结果；查询参数和链接片段在上报前移除。开启 Do Not Track 时不发送统计，统计加载失败不影响抽取或房间功能。
