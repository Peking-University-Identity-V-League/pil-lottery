# 第五人格随机抽取工具 · PIL Identity V Lottery Tool

为第五人格对局随机生成 4 名求生者、1 名监管者，以及各自的人格配置和监管者辅助特质。

**[在线使用](https://pkuidv.com/lottery/)**

## 功能

- **随机阵容**：一次抽取 4 名不重复的求生者和 1 名监管者。
- **人格配置**：分别设置求生者与监管者的终极人格数量，支持随机或指定 0、1、2 个；求生者可选择必点「绝处逢生」。
- **辅助特质**：可以随机抽取，也可以关闭「抽取辅助特质」，由监管者自己选择。
- **完整人格树**：按 130 点人格点数生成配置，点击人格图标可查看层数和人格说明。
- **卡池**：分别管理求生者、监管者和辅助特质的抽取范围。
- **单项重抽**：保留其他结果，单独更换某个角色、人格或监管者辅助特质。
- **结果分享**：一键复制完整结果，或只复制角色和终极人格的简略结果。
- **揭晓动画与音效**：支持跳过动画，也可关闭音效。

## 使用方式

1. 在「卡池」中选择参与抽取的角色和辅助特质。
2. 设置双方的终极人格数量、是否必点「绝处逢生」、是否抽取辅助特质。
3. 点击「抽取结果」生成本局配置。
4. 点击人格树查看详情，按需单项重抽，或复制结果。

卡池、抽取选项和音效设置会保存在当前浏览器中。

## 访问与操作统计

线上页面接入 PIL 现有 Umami 站点，使用 `lottery` 标签，可按 `/lottery/` 路径筛选访问量。

记录抽取、单项重抽、复制结果或人格树图片、查看人格树、卡池调整、抽取设置变化和跳过动画。操作数据只包含固定选项、双方类别、卡池数量和复制是否成功；不上传抽中的角色、人格配置、具体卡池名单、结果文本、图片或剪贴板内容，不设置用户身份。URL 查询参数和片段会被移除，来源只保留域名；尊重浏览器 Do Not Track，仅在线上域名启用。统计服务被拦截或失败时不影响工具使用。
